# Galaxy Space Explorer 🌌🚀

A visually immersive, single-page website themed around the mysteries of the galaxy. Built using React and Vite, this project focuses on modern frontend structures and responsive design.

## 🚀 Live Demo
Explore the galaxy here: [Galaxy Space Website](https://space-galaxy-website.web.app/)

## 🛠️ Tech Stack
* **Framework:** React.js (Vite)
* **Styling:** Bootstrap 5 & CSS
* **Environment:** Node.js
* **Hosting:** Firebase Hosting

## ✨ Key Features
* **Space-Themed UI:** Engaging visuals with a galaxy aesthetic.
* **Fully Responsive:** Seamlessly works on mobile, tablets, and desktops using Bootstrap classes.
* **Vite-Powered:** Fast development and optimized build performance.
* **Deployed via Firebase:** Live and accessible globally.

## 📁 Project Structure
* `src/`: Contains React components and JSX logic.
* `public/`: Static assets like icons and background images.
* `dist/`: Production-ready build files.
